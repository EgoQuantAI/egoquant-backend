EgoQuant is a wealth-advisory agent in which deterministic code decides and the language model only explains. A 25-question questionnaire (Grable-Lytton items, a loss-capacity section, a knowledge check) and a seven-round Risk Game place each investor in a category from C1 to C5: the lower of what they can afford to lose and what they are willing to risk. A market-data agent feeds an optimiser that proposes a portfolio and simulates 10,000 paths towards the investor's goal; a behaviour agent can only tighten limits, using the investor's trade history; an independent Risk Engine re-checks every proposal and fails closed. An advisor chat explains the results and checks "what if" trades against the investor's limits; its numbers are grounded, advice is filtered and personal data is redacted. A news briefing follows each holding. Any report can be sealed: a salted fingerprint on a public test blockchain (Ethereum Sepolia) shows later that it was not changed. The system is live, backed by an automated test suite, live AI red-team runs, a security self-assessment and public source code.
